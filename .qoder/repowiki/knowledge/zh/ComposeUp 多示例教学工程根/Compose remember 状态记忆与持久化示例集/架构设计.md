模块以 `RememberHub.kt` 作为单一入口 Hub，内部用 `RememberTopic` 枚举（Basic / Saveable / Serializable / Retain / Observers）驱动一个 `LazyColumn` 列表，根据选中项路由到对应的 Demo Composable；每个 Demo 文件独立展示一个子主题，彼此之间无相互依赖，仅共同依赖 `com.example.composeup.flow` 下的 UI 组件（ButtonRow、CodeBlock、LogBox、Stage、Note、SectionTitle）。`RememberHub` 使用 `rememberSaveable` 保存当前选中的 topic，并通过 `BackHandler` 提供返回导航，构成「Hub → Topic List → 具体 Demo」的单向层级结构。
