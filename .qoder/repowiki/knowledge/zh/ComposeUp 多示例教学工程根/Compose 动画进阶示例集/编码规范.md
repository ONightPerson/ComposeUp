- 每个示例文件对外暴露一个接收 `Modifier` 参数的顶层 `@Composable`，由 `AnimationHub` 统一注入布局空间。
- 示例间通过 `AnimationTopic` 枚举集中声明 title / summary / keywords，再由 Hub 的 `when` 分支分发到对应 Demo。
- 高频变化的位移 / 缩放 / 旋转 / 透明度走 `Modifier.graphicsLayer { }` 或 `Modifier.offset { }` 的 lambda 版本，避免触发重组与重测量。
- `rememberInfiniteTransition` 与 `InfiniteTransition.animate*` 调用一律传入 `label` 参数，遵循 Compose 1.10 的废弃重载约束。
- 列表项动画使用 `LazyItemScope.Modifier.animateItem()` 而非已改名的 `animateItemPlacement`，并为每个 item 提供稳定唯一的 `key`。
