模块以 `AnimationHub.kt` 作为入口：内部用 `AnimationTopic` 枚举声明 6 个主题（ValueState / Transition / VisibilityContent / SizeAndList / Specs / Gesture），在 `LazyColumn` 中渲染标题、摘要与关键词；选中后通过 `BackHandler` + `Scaffold` 顶部导航返回上一级，并用 `when` 分发到对应 Demo 文件。

- 每个 `.ktl` 文件是一个独立的可交互示例，对外暴露一个带 `Modifier` 参数的顶层 `@Composable`，由 Hub 注入布局空间。
- `AnimationWidgets.kt` 提供包内复用的展示组件（如 `DemoStage` / `DemoButtonRow` / `DemoOptionChips`），被各示例复用以保持 UI 一致。
- 依赖方向单向：Hub → 各 Demo；Demo 之间不互相引用，仅共享 `AnimationWidgets`。
- README.md 同时充当文档与心智模型说明，按「谁管理动画状态」三层（值动画 / 组件级 API / Animatable）组织内容，并给出选型速查与实践清单。
