模块按职责分为四层：
- UI 层 `ScreenRecordHub.kt`：Compose 入口，负责权限申请（RECORD_AUDIO、POST_NOTIFICATIONS、READ_MEDIA_VIDEO）、调用 MediaProjectionManager 获取屏幕捕获 Intent，并通过 Service Action 控制录制生命周期。
- 状态层 `RecordingState.kt`：单例 `MutableStateFlow<Boolean>`，作为 Compose UI 与后台 Service 之间的录制状态桥接。
- 服务层 `ScreenRecordService.kt`：前台 Service，接收 ACTION_START/ACTION_STOP，创建 NotificationChannel，通过 MediaProjection → VirtualDisplay → MediaRecorder 将屏幕帧编码为 H.264+AAC MP4。
- 存储层 `MediaStoreUtils.kt`：封装 MediaStore Video 的写入（含 IS_PENDING 标记）、查询（按 RELATIVE_PATH="Movies/ComposeUpRecordings" 过滤）与删除（Android R+ 使用 createDeleteRequest 返回 IntentSender，Q 上处理 RecoverableSecurityException），并定义 `RecordedVideo` data class。
依赖方向单向：UI → Service/MediaStoreUtils；Service → RecordingState/MediaStoreUtils；无反向依赖。
