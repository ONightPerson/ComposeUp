模块按 Material3 的 Theme 三要素拆分为三个文件：Color.kt 暴露一组顶层 Color 常量（Purple/PurpleGrey/Pink 各一套 40/80 色值）；Type.kt 提供全局 Typography 实例，目前仅覆盖 bodyLarge；Theme.kt 组合二者并暴露入口 Composable ComposeUpTheme，内部根据 isSystemInDarkTheme() 与 Build.VERSION.SDK_INT >= S 动态选择 dynamicLight/darkColorScheme 或静态 Light/DarkColorScheme，最终通过 MaterialTheme(colorScheme, typography, content) 注入子树。依赖方向单向：Theme.kt → Color.kt + Type.kt，其他 UI 层仅消费 ComposeUpTheme。
