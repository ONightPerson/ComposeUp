- 每个副作用 API 独占一个 `*Demo.kt` 文件，并在文件名前加序号（①~⑧），与 README 和 `EffectTopic` 枚举顺序保持一致。
- Demo 通过 `rememberSaveable` 持有用户输入状态（如 pulseRateMs、userType、url），配合不同 key 传入 Effect 以演示「key 变化重启」语义。
- 需要与外部世界交互的 Demo 统一使用包内共享的 `FakeAnalytics` 作为分析 SDK 替身，避免引入真实第三方依赖。
- 所有可观察的状态变更都通过 `LogBox` 打印时机日志，使组合/重组/取消等不可见生命周期可视化。
- 对长生命周期 effect 中捕获的可变回调/值，统一用 `rememberUpdatedState` 包裹以避免 stale closure，并与「错误用法」并排对比展示。
