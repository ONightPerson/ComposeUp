模块以 `SideEffectsHub.kt` 为入口：内部定义 `EffectTopic` 枚举（title/summary/keywords），由 `SideEffectsHub()` 渲染话题列表并 `when` 分发到各 Demo composable；每个 Effect 对应一个独立文件（如 `LaunchedEffectDemo.kt`、`ProduceStateDemo.kt`），遵循「一 API 一文件」的扁平结构。`SideEffectsWidgets.kt` 提供包内共享 UI 组件（CodeBlock、LogBox、Stage、ButtonRow、OptionChips、Readout）以及非 Compose 对象 `FakeAnalytics`，被所有 Demo 复用作为外部系统替身。依赖方向单向：Hub → 各 Demo → SideEffectsWidgets；Demo 之间不互相引用。README.md 与类注释共同构成文档化契约，严格对齐官方文章顺序。
