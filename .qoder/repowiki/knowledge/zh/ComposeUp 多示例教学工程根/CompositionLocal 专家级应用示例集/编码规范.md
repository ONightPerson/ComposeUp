- 每个 Demo 文件顶部声明一个 `val LocalXxx = staticCompositionLocalOf / compositionLocalOf { ... }` 的全局 Local，并在对应 Demo 根 Composable 内用 `CompositionLocalProvider(LocalXxx provides value)` 提供值。
- 深层次的 UI 组件通过 `LocalXxx.current` 直接读取上下文数据，避免将参数逐层透传。
- 共享的展示型小组件（`LocalRow`、`Stage`、`ButtonRow`、`Note`、`DemoButton`）统一放在 `LocalWidgets.kt` 并以 `internal` 修饰，供同包 Demo 复用。
- 需要跨层传递的横切能力（如权限、埋点）采用「接口 + 默认实现」形式（`PermissionHandler`、`AppTracker`），由根层提供具体实现，子组件仅消费接口。
