- Worker 类继承 CoroutineWorker，doWork() 返回 Result.success/failure/retry，并通过 setProgress(Data) 报告中间进度。
- Worker 的 inputData/outputData 键名集中在 companion object 中以 const val 形式声明，避免魔法字符串散落。
- UI 层使用 Flow（getWorkInfoByIdFlow / getWorkInfosForUniqueWorkFlow）观察 WorkInfo 状态，配合 LogBox 按时间顺序打印 ENQUEUED → RUNNING → SUCCEEDED 等流转。
- 三个 Demo 共用 WorkManagerWidgets.kt 中的小组件（CodeBlock / LogBox / Stage / ButtonRow / OptionChips / Readout），避免在每个示例中重复实现 UI。
- 周期任务通过 enqueueUniquePeriodicWork(name, policy, request) 提交，并以 ExistingPeriodicWorkPolicy（KEEP / REPLACE / UPDATE）对比不同冲突策略的行为差异。
