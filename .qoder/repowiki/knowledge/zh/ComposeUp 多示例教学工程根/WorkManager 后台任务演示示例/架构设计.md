模块以 `WorkManagerHub.kt` 作为入口：内部用 `WorkManagerTopic` 枚举维护三个子示例（OneTime / Periodic / Update），根据选中项在 Scaffold 中切换渲染 `OneTimeWorkDemo`、`PeriodicWorkDemo`、`UpdateWorkDemo`。
- 业务逻辑层：`Workers.kt` 定义两个 `CoroutineWorker` 子类 `UploadWorker`（一次性上传）和 `DailySyncWorker`（周期同步），每个 Worker 在 companion object 中集中声明 `inputData`/`outputData` 的 key 常量。
- UI 展示层：`WorkManagerWidgets.kt` 提供包内复用的小组件（CodeBlock / LogBox / Stage / ButtonRow / OptionChips / Readout），供三个 Demo 共享；日志输出统一走 `LogBox` 把后台 `WorkInfo` 状态变化按时间打印到屏幕。
- 依赖方向单向：Demo → Workers + WorkManagerWidgets → androidx.work；模块不持有全局单例，WorkManager 实例在各 Demo 中按需获取。
- 文档与实现一一对应：`README.md` 详细记录三个示例的递进关系、API 速查表与实践清单，是模块的设计说明而非普通注释。
