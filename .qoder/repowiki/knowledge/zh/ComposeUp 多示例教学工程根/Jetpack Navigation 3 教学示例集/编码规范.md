- 每个 Demo 自管一个 `rememberNavBackStack` 与 `NavDisplay`，Demo 之间不共享返回栈，仅通过 `Nav3Hub` 的 topic 枚举切换。
- NavKey 统一声明为 `@Serializable` data class/object 并实现 `NavKey`，作为栈中的引用类型而非内容本身。
- 装饰器链以 `rememberSaveableStateHolderNavEntryDecorator()` 放首位，再叠加 `rememberViewModelStoreNavEntryDecorator()`、`rememberResultEventBusNavEntryDecorator()` 等能力型装饰器。
- Deep Link 匹配采用 `matchers.mapNotNull { it.match(request) }.maxOrNull()` 取最优匹配结果，并用 `withBackStack` 把匹配结果包装成合成返回栈。
- 教学 UI 通过 `BackStackView` 可视化当前栈、`LogBox` 按时间打印事件，把 nav3 幕后行为（栈增删、decorate/onPop、结果收发）显式画出来。
