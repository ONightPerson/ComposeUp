模块以 `Nav3Hub.kt` 作为话题入口：一个 `Nav3Topic` 枚举 + `Nav3Hub` Composable 列出 8 个主题并分发到对应 Demo。

- 共享基础设施集中在三个文件：`Nav3Keys.kt`（所有示例共用的 `@Serializable` NavKey，如 HomeKey/DetailKey/UserProfileKey/DialerKey）、`Nav3Widgets.kt`（BackStackView / LogBox / Pane / CodeBlock 等教学 UI 组件）、`README.md`（API 版本核对与踩坑记录）。
- 8 个 Demo 各自独立持有自己的 `rememberNavBackStack` + `NavDisplay` + `entryProvider`，互不依赖；`Nav3Activity.kt` 是独立的真实 deep link 入口 Activity，在 `onCreate` 中用 `DeepLinkMatcher` 匹配 Intent 生成初始返回栈。
- 依赖方向单向：Demo → Nav3Keys/Nav3Widgets；Nav3Activity → DeepLinkMatcher 生态；模块对外只暴露 `Nav3Hub` 和 `Nav3Activity` 两个入口。
- 使用 nav3-runtime 1.2.0 的 `ResultEventBus`、`DeepLinkRequest`、`SceneStrategy`、`NavEntryDecorator` 等新 API，而非旧版自定义 ResultStore / URI 解析。
