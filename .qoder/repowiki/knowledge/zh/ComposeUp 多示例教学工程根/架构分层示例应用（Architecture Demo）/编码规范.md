- UI 层通过 sealed interface `NewsEvent` 上报用户操作，ViewModel 在 `onEvent` 中统一分派，界面组件不直接调用业务逻辑。
- 领域层以 UseCase 类封装单一用户目标，并通过 `operator fun invoke()` 提供简洁调用点，构造函数注入 `NewsRepository` 抽象。
- 数据层通过 `NewsRepository` 接口暴露 `StateFlow<NewsSnapshot>` 与 suspend 方法，具体实现（如 `InMemoryNewsRepository`）由上层工厂注入。
- 状态采用归一化设计：`NewsSnapshot` 保存实体与顺序，`NewsUiState` 仅提供派生属性（`visibleArticles`、`selectedArticle`、`bookmarkCount`），避免多份可写副本。
