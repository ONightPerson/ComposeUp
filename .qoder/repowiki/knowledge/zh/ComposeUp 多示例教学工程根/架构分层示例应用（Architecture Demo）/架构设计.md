模块按 Clean Architecture 三层划分：
- data/：实现 `NewsSource` 函数式接口（`DemoNewsSource` 模拟网络延迟返回文章）和 `InMemoryNewsRepository`（内存中维护 `articlesById` + `feedIds` 的归一化快照），对外暴露 `NewsRepository` 接口。
- domain/：定义不可变数据模型（`NewsArticle`、`NewsSnapshot`、`RefreshStatus`）、`NewsRepository` 接口以及三个以用户目标命名的 UseCase（`ObserveNewsUseCase`、`RefreshNewsUseCase`、`ToggleBookmarkUseCase`），仅依赖 Repository 抽象。
- ui/：`NewsViewModel` 组合 UseCase 并通过 `SavedStateHandle` 持久化筛选与选中 ID，用 `combine` + `stateIn` 产出 `NewsUiState`；`NewsHomeScreen` / `NewsDetailScreen` / `NewsWidgets` 只消费 StateFlow 并上报 `NewsEvent` 事件。
- 顶层 `ArchitectureHub.kt` 作为入口，使用 `viewModelFactory` 注入 Repository 与 UseCase，并在 Scaffold 中根据 `selectedArticleId` 切换首页与详情页，同时处理 BackHandler。
依赖方向严格单向：ui → domain → data，UI 不感知 Repository 或数据源。
