模块以 `FlowHub.kt` 作为入口，用 `FlowTopic` 枚举维护 6 个话题（ColdFlow / Operators / StateFlow / SharedFlow / Backpressure / Lifecycle），在列表页与二级 Demo 页面之间切换并处理系统返回键。
- 数据层：`FlowSources.kt` 提供纯 Kotlin 的假数据源（`articleFeed`、`searchArticles`、`sensorStream`、`ALL_ARTICLES`），不依赖 Android，被各 Demo 复用。
- UI 层：每个主题一个独立文件（`ColdFlowDemo.kt`、`OperatorsDemo.kt`、`StateFlowDemo.kt`、`SharedFlowDemo.kt`、`BackpressureDemo.kt`、`LifecycleCollectDemo.kt`），各自封装一个顶层 `@Composable` 函数供 Hub 调用。
- 共享组件：`FlowWidgets.kt` 暴露包内复用的 UI 原语（`FlowRow`、`CodeBlock`、`LogBox`、`Stage`、`ButtonRow`、`OptionChips`、`Readout`），用于把「看不见的时间行为」可视化到屏幕。
- 依赖方向单向：Hub → Demo → FlowSources + FlowWidgets；Demo 之间互不引用，便于逐个运行。
