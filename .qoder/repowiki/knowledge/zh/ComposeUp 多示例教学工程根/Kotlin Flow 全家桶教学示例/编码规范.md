- 每个示例主题独立成文件并以同名的顶层 `@Composable` 函数暴露给 `FlowHub`，Hub 内用 `when` 分支分发。
- 共享的假数据源集中在 `FlowSources.kt`，以 `internal fun` 形式提供 `flow { }` 构造的冷流，避免在各 Demo 中重复模拟网络/传感器延迟。
- UI 辅助组件统一放在 `FlowWidgets.kt` 并以 `internal` 修饰，包括代码块、日志框、舞台容器、按钮行、单选 Chip 和数值展示行。
- 演示运行时事件通过 `LogBox` 追加字符串并按时间顺序渲染，最新记录置顶，使 emit/collect/生命周期等时序行为可视化。
- 热状态用 `MutableStateFlow` 私有持有、对外 `asStateFlow()` 只读暴露，修改一律走 `update { copy(...) }` 而非 `.value =`。
- 一次性事件用 `MutableSharedFlow(replay = 0, extraBufferCapacity = N, onBufferOverflow = DROP_OLDEST)` 配合 `tryEmit` 发送，避免阻塞发送方。
