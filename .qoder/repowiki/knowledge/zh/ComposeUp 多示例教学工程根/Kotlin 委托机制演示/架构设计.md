模块按委托类型划分为三个并列文件：`StandardPropertyDelegates.kt` 展示 `lazy / observable / vetoable / notNull / by map` 五种标准库委托；`CustomPropertyDelegate.kt` 实现 `ReadWriteProperty`、`ReadOnlyProperty` 与 `provideDelegate`（含 `PrefInt`、`ClampedInt`、`LoggingLazy`、`ConfigField` + `ConfigRegistry`）；`ClassDelegation.kt` 用 `interface UserRepository by impl` 实现可叠加的装饰器链（`RemoteUserRepository` → `CachingUserRepository` → `LoggingUserRepository`）。`DelegatesDemo.kt` 作为唯一入口，按编号顺序串联所有场景并打印控制台输出。依赖方向单向：Demo → 标准委托 / 自定义委托 / 类委托，三者之间无相互引用。
