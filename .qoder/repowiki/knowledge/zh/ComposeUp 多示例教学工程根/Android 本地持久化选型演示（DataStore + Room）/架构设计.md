模块严格遵循 Guide to App Architecture 的分层模型：
- UI 层：`DatastoreHub.kt` 作为入口 Hub，按 `StorageTopic` 枚举分发到 `PreferencesDemo` / `ProtoDemo` / `RoomDemo` 三个 Composable 页面；每个 Demo 持有对应 ViewModel。
- ViewModel 层 (`ui/viewmodel/`)：`*ViewModel` 仅暴露 `StateFlow<UiState>`，通过 `viewModelScope` 调用 Repository 的挂起函数，使用 `stateIn(SharingStarted.WhileSubscribed)` 将 Flow 转为 StateFlow。
- Data 层 (`data/`)：Repository (`data/repository/`) 是系统唯一真实数据源入口，屏蔽底层存储细节；`data/local/` 下按存储技术分目录——`local/datastore/` 提供 `Serializer<T>` 实现（Gson/Moshi/Proto 三种序列化方案），`local/room/` 提供 `AppDatabase` + `ProductDao`；`data/model/` 存放跨层共享的 Entity/DataClass。
- 依赖方向单向：UI → ViewModel → Repository → (DataStore / Room)；Composable 不直接访问 DataStore 或 DAO。
- 手动 DI：Repository 由 ViewModel 构造函数注入，未引入 Hilt，以简化演示。
