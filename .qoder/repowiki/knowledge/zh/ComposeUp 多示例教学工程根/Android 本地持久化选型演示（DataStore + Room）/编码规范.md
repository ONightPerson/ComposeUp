- Repository 通过扩展属性 `Context.dataStore` 获取 DataStore 实例，并在 Flow 链路上用 `catch { IOException }` 回退到默认值再 `map` 为业务模型。
- ViewModel 暴露 `val uiState: StateFlow<T>`，并使用 `stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), initialValue)` 将 Repository 的 Flow 转为冷启动安全的 StateFlow。
- 用户操作统一封装为 ViewModel 的 suspend 方法，内部通过 `viewModelScope.launch` 调用 Repository 的 suspend 函数，保持 Action 向上、State 向下的单向数据流。
- DataStore 的自定义对象持久化采用双层 Serializer：外层实现 `androidx.datastore.core.Serializer<T>` 负责文件流 I/O，内层委托 `kotlinx.serialization.KSerializer` 完成 JSON 编解码。
- Room 数据库通过单例 `companion object.getDatabase(context)` 懒加载，并开启 `fallbackToDestructiveMigration(true)` 以简化演示环境的版本迁移。
