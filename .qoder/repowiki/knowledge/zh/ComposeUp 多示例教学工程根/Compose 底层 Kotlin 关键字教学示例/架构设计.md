模块以 `KeywordsHub.kt` 作为入口：内部用 `KeywordTopic` 枚举维护 5 个话题（Operator / Infix / Invoke / Inline / LambdaModifiers），根据 `selected` 状态在列表页与具体 Demo 页面之间切换，并通过 `BackHandler` 实现返回键回退到列表。

- 每个关键字一个独立文件（`OperatorDemo.kt`、`InfixDemo.kt`、`InvokeDemo.kt`、`InlineDemo.kt`、`LambdaModifiersDemo.kt`），彼此不互相依赖，仅通过包内可见的共享 UI 组件协作。
- `KeywordsWidgets.kt` 集中提供包内复用的小组件（`KeywordRow`、`SectionTitle`、`Note`、`CodeBlock`、`LogBox`、`Stage`、`ButtonRow`、`DemoButton`），所有 Demo 页面统一使用这些 internal 组件渲染说明文本、代码片段和运行结果。
- 依赖方向单向：`KeywordsHub` → 各 Demo → `KeywordsWidgets`；Demo 之间无交叉引用，便于逐个阅读与替换。
- `README.md` 是文档化契约，逐条对照 Compose 1.10.4 sources jar 中 `Dp`、`Modifier`、`EnterTransition`、`CompositionLocal` 等源码，标注哪些 API 是 `inline`/`infix`/`operator`，作为本模块事实依据。
