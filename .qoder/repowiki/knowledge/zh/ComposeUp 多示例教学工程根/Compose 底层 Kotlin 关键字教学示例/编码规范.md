- 每个关键字主题拆分为独立 Demo 文件，由 `KeywordsHub` 通过 `when (current)` 路由到对应 `*Demo` 可组合函数，Demo 之间零相互引用。
- 所有跨 Demo 复用的 UI 片段（卡片、代码块、日志框、舞台容器、按钮行）集中在 `KeywordsWidgets.kt` 并以 `internal fun` 暴露，Demo 文件只消费不重复实现。
- 对纯 Kotlin 编译期机制（inline/crossinline/noinline/非局部返回）采用「收集 String 日志 → `LogBox` 渲染」的方式呈现，把不可见的行为转化为可视输出。
- 示例代码片段统一通过 `CodeBlock` 以等宽字体 + 深色背景展示，并与右侧 `Stage` 容器并列，形成「代码 + 实时效果」的固定布局模式。
- 涉及 Compose 源码行为的断言均以注释形式引用 sources jar 中的实际签名（如 `@Stable inline operator fun Dp.plus`、`inline val Int.dp`），而非凭经验声明。
