模块以 `NestedScrollHub.kt` 作为统一入口：内部用 `NestedScrollTopic` 枚举维护 5 个示例的标题、摘要与关键词，并在列表页与详情页之间通过 `rememberSaveable` 状态切换；详情页由 `Scaffold` + `BackHandler` 提供返回导航。

五个示例文件各自独立、互不依赖，按难度递进组织：
- `CollapsingHeader.kt`：手写 `NestedScrollConnection` 实现折叠 Header（四阶段全覆盖）。
- `DispatcherDemo.kt`：用 `NestedScrollDispatcher` 让自绘控件参与嵌套滚动。
- `SameDirectionNestingDemo.kt`：演示 `Column(verticalScroll) { LazyColumn }` 测量约束崩溃及四种解法（合并 / 固定高度 / 退化为 Column / 阻断冒泡）。
- `OrthogonalNestingDemo.kt`：展示横向 Pager 与纵向 LazyColumn 的正交嵌套天然无冲突。
- `Material3CoopDemo.kt`：演示 `TopAppBarDefaults.*ScrollBehavior`、`ModalBottomSheet`、`PullToRefreshBox` 的内置协作。

`NestedScrollWidgets.kt` 提供包内复用的 DemoRow / DemoNote / DemoPlaceholder 等辅助 UI 组件，被 Hub 和各示例共同引用。所有示例基于 Compose BOM `2026.02.01`，使用 `androidx.compose.ui.input.nestedscroll` 包名（1.10 新 API），README.md 同时充当教学文档与 API 版本对照表。
