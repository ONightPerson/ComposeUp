### NavKey
- 定义：Navigation 3 中目的地内容的引用标识，需实现 `NavKey` 接口并标注 `@Serializable`，通常是简单的 data class 或 object。栈里只存 key，内容由 `entryProvider` 解析为 `NavEntry`。

### NavEntry
- 定义：一个目的地的「内容 + metadata」组合体，由 `entryProvider` 把 `NavKey` 解析而来，包含 `contentKey`、`Content()` 和 `metadata`。`NavDisplay` 最终渲染的是 NavEntry 而非 NavKey。

### NavDisplay
- 定义：Navigation 3 的观察-渲染容器：观察返回栈、把 key 解析成 NavEntry 并负责转场动画与返回逻辑。它是 nav3 与 UI 的唯一交汇点。

### NavEntryDecorator
- 定义：对栈中每个 NavEntry 统一加料的装饰器抽象，实现 `decorate`（进入组合时包裹 `entry.Content()`）和 `onPop`（离开时清理）。项目内置了 saveable、ViewModelStore、ResultEventBus 三个装饰器，也支持自定义日志/埋点/注入。
- 别名：装饰器

### Scene / SceneStrategy
- 定义：`Scene` 是渲染一个或多个 NavEntry 的布局单元；`SceneStrategy.calculateScene` 根据当前栈决定如何布局（如双栏、对话框），返回 null 则回退默认单页策略。`SceneDecoratorStrategy` 再对算出的 Scene 做第二阶段加工（如统一加顶栏）。
- 别名：场景、场景策略

### Deep Link Matcher
- 定义：Navigation 3 中从 Intent/URI 匹配目标目的地的组件。1.2.0 起使用 `DeepLinkRequest` + `DeepLinkMatcher`，内置 `UriDeepLinkMatcher`（pattern + serialization 抽参）和 `StaticKeyDeepLinkMatcher`（固定 action/filter），也可继承 `DeepLinkMatcher<T,R>` 实现自定义 opaque URI 匹配。
- 别名：深链匹配器、DeepLinkMatcher

### ResultEventBus
- 定义：Navigation 3 1.2.0 起提供的目的地间返回结果总线，通过 `LocalResultEventBus` 注入。发送方调用 `sendResult(resultKey, value)` 后 pop，接收方用 `ResultEffect`（事件式、协程可挂起）或 `conflateAsState`（状态式、保留最新值）消费。显式 key 与类型派生 key 互不相通。
- 别名：结果总线

### 合成返回栈
- 定义：Deep Link 匹配成功后，通过 `.withBackStack { matchResult -> listOf(...) }` 生成的初始返回栈，让从外部链接进入的页面能按返回键逐级退回（例如先回首页再逐层退出）。
